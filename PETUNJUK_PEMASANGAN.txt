PAKET MATRIKULASI R9 — VERCEL + DOCKER + FRANKENPHP

1. Ekstrak ZIP. Root folder harus berisi Dockerfile dan Caddyfile.
2. Salin logo asli dari website Laragon ke public/logo/ (logo_kemsos.png dan sr-image.png).
3. Buat Upstash Redis melalui Vercel Marketplace. Environment: UPSTASH_REDIS_REST_URL dan UPSTASH_REDIS_REST_TOKEN.
4. Buat Vercel Blob dengan akses PRIVATE dan hubungkan ke project. Environment: BLOB_READ_WRITE_TOKEN.
5. Tambahkan APP_ENV=production, GAS_URL, dan GAS_API_KEY di Vercel.
6. GAS_API_KEY harus sama dengan PHP_RAPOR_API_KEY di Code.gs aktif. Salin nilainya sebelum menimpa config.php lama.
7. Deploy dari Git atau Vercel CLI, bukan upload file PHP satu per satu.
8. Jika project lama memakai Static preset: vercel link lalu vercel project update --framework container --yes.
9. Deploy: vercel deploy --prod. Uji /healthz.php.

Baca README_VERCEL.md untuk instruksi rinci, Docker lokal, migrasi tanggal TTD, dan pemeriksaan.
