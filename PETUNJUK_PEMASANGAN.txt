PEMBARUAN WEBSITE RAPOR MATRIKULASI — NIP WALI KELAS
Build Apps Script acuan: MATRIKULASI-20261117-R4
Kompatibilitas target: PHP 7.2+

ISI PAKET
- auth.php                  Session login, pembatasan kelas, CSRF, timeout.
- config.php                Koneksi ke Apps Script; API key server-ke-server.
- validasi_wali_kelas.php   Login NIP + konfirmasi NIP.
- index.php                 Daftar siswa yang dibatasi pada kelas akun.
- rapor.php                 Detail rapor, catatan wali kelas, NIP tanda tangan.
- logout.php                Logout POST + CSRF.
- Code.gs                   Apps Script R4 dengan endpoint auth_wali_kelas dan API key.
- PETUNJUK_PEMASANGAN.txt   Panduan deployment.

PENTING: MEKANISME LOGIN
Login mengikuti permintaan: dua kolom NIP dan konfirmasi NIP harus sama.
Server PHP kemudian memeriksa NIP pada sheet verif kolom E dan hanya menerima
baris yang memenuhi role Wali Kelas berdasarkan fungsi cocokRole_ pada Apps Script.
Nama resmi dan daftar kelas diambil dari sheet verif. Daftar kelas disimpan pada
session server dan dipakai untuk membatasi index.php serta rapor.php.

Catatan keamanan: konfirmasi NIP memastikan dua input sama, tetapi bukan faktor
rahasia tambahan. NIP yang diketahui orang lain tetap dapat dipakai untuk login.
Untuk autentikasi yang kuat, tambahkan PIN/password atau OTP sebagai faktor rahasia.

LANGKAH PEMASANGAN
1. Cadangkan folder website dan Apps Script lama.
2. Ekstrak ZIP ini. Salin file PHP ke folder website yang sama:
   auth.php, config.php, validasi_wali_kelas.php, index.php, rapor.php, logout.php.
3. Buka Code.gs pada Apps Script yang saat ini dipakai. Ganti isi project Apps Script
   dengan isi Code.gs dari paket ini, atau terapkan perubahan yang dijelaskan di bawah.
4. Pastikan konstanta SPREADSHEET_ID tetap mengarah ke spreadsheet yang benar.
5. Simpan Apps Script, lalu Deploy > Manage deployments > Edit deployment > New version
   dan deploy ulang sebagai Web App. Gunakan konfigurasi akses yang memang diperlukan
   oleh server PHP. URL deployment harus tetap sama atau sesuaikan GAS_URL di config.php.
6. API key sudah disamakan antara Code.gs dan config.php pada paket ini.
   Jangan mengubah salah satunya tanpa mengubah pasangannya.
7. Pastikan PHP cURL aktif dan ekstensi OpenSSL aktif. Verifikasi SSL tetap aktif.
   Jika cURL di Laragon gagal memvalidasi sertifikat CA, pasang/atur file CA bundle
   pada curl.cainfo di php.ini; jangan menonaktifkan SSL verification.
8. Buka validasi_wali_kelas.php, masukkan NIP yang terdaftar pada verif kolom E
   di baris dengan role Wali Kelas, lalu ulangi NIP pada kolom konfirmasi.
9. Setelah login, index.php menampilkan nama resmi, NIP, dan kelas yang diampu.
10. Uji satu siswa untuk setiap kelas. Buka rapor dan periksa NIP tanda tangan serta
    Catatan Wali Kelas. Cetak ke PDF dan pastikan bagian catatan dan tanda tangan tampil.

SUMBER DATA YANG DIPAKAI (SESUAI CODE.GS R4)
- verif: nama resmi pada kolom C, label kelas/role pada kolom B, NIP pada kolom E.
  Filter role menggunakan fungsi cocokRole_(row, "WALI_KELAS") dari Apps Script.
- walas: nama siswa kolom E, kelas kolom G, catatan kolom J (J2:J1000).
  Fungsi petaWalas_ dan getCatatanWaliKelasForRapor mencocokkan nama + kelas.
- Sheet 101: identitas siswa pada kolom B-D; detail rapor mengembalikan nip_wali_kelas
  dan catatan_wali_kelas.

PERUBAHAN API APPS SCRIPT
- doGet action=auth_wali_kelas&nip=... memvalidasi NIP terhadap verif.
- action=list, action=detail, dan action=auth_wali_kelas kini memerlukan api_key.
- config.php mengirim api_key otomatis pada setiap panggilan API.
